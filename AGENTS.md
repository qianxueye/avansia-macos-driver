# Repository instructions

Use English for source code and repository documentation. Preserve the single-card protocol allowlist, explicit K geometry, manufacturer covering beneath K, device mutex, durable uncertain-card state, and no automatic print retries. Do not publish user documents, device captures, personal identifiers, proprietary SDK binaries or official product artwork.

Hardware reads require idle-state checks and the shared nonblocking lock. Settings writes must use discovered logical identities, validate a fresh descriptor and expected current value, perform one write and verify exact readback. Unknown and action descriptors remain read-only.

Use synthetic fixtures for public tests. Physical printing, maintenance movement and firmware changes require explicit user authorization. Keep software checks, installation, device completion and visual acceptance distinct.
